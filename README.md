# Hi, I'm Anto 👋

Python developer working on **web scraping, RPA and browser automation**. Day to day that means building scrapers and form-filing bots that keep working when the site doesn't want them to: TLS fingerprinting, Cloudflare/Akamai challenges, proxy rotation, and reverse engineering the private APIs behind a page so a slow browser job becomes a fast HTTP one.

- 🕷️ Web scraping at scale: requests/aiohttp/curl_cffi, lxml, pagination, validation, scheduled crawls
- 🤖 RPA with Playwright: multi-step portal workflows, queue-driven workers, per-step status and retries
- 🛡️ Anti-bot: browser fingerprints, JA3/JA4, stealth browsers (Camoufox), CAPTCHA/Turnstile handling
- ⚙️ APIs & infra: FastAPI, Redis, Docker, GitLab CI/CD, AWS, Linux
